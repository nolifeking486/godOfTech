# Music Download With Album Art

using yt-dlp and python -> getmusic.py

```
python3 ~/path/getmusic.py playlist "url"
python3 ~/path/getmusic.py single "url"
```

will save the file in current directory

## Cliamp lua plugin

attached a custom keybind `alt g` to execute yt-dlp command from cliamp and download the track to directory from which cliamp was opened.  
check cliamp plugins -> save-track.lua
