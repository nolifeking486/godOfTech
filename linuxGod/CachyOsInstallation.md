## System Verification
Run these commands in the terminal to verify hardware integration:
*   `sudo pacman -Syu` (Update core system).
*   `nvidia-smi` (Verify Wayland is using proprietary NVIDIA drivers).
*   `lsblk` (Verify the kernel detects the secondary internal HDD).
*   `zramctl` (Verify ZRAM memory compression is active).

## 6. Fixing Display Scaling (1080p on Wayland)
*   Open **Display Configuration** in KDE Settings.
*   Change **Global Scale** from 100% to 125%.
*   Change **Cursor Size** in Appearance settings to 30px or 36px to match.

## 7. Auto-Mounting the Internal HDD
By default, Linux requires root passwords to access internal drives. To automate this:
1. Install GNOME Disks: `sudo pacman -S gnome-disk-utility`
2. Open Disks, select the HDD, and click the specific partition block.
3. Click the gear icon (⚙️) -> **Edit Mount Options...**
4. Toggle off **User Session Defaults**.
5. Ensure **Mount at system startup** is checked.
6. Save and reboot.

## 8. Cleaning Up Windows Ghost Files
When migrating a shared HDD from Windows to Linux, you can safely delete the following hidden system folders generated by Windows:
*   `$RECYCLE.BIN`
*   `System Volume Information`
*   `Recovery`
*   `msdownld.tmp`
*   Any stray `.log`, `.tmp`, or `qhlogs` files in the root directory.
