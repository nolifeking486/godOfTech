# Introduction

* BASH : Bourne Again Shell.
* It is CLI (Command Line Interpreter), interface between User and OS

## Commands

including built-in commands and CLI programs

### Files and Directories

`rm` : remove files/Directories  
`shred` : overwrite and delete files -> secure delete  
`touch` : create empty file, change file details  
`cat` : display content of files, concatenate files  
`cp` : copy files and directories  
`mv` : move files/dirs, rename files/dirs  
`open` : open files/dirs using default apps  

### C++

`g++ filename.cpp` : Compile. make sure to save first, no flags will default to a.out executable  
`./a.out` : Run
